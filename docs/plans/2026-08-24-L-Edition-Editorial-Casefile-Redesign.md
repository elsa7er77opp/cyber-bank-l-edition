# CYBER BANK L EDITION — Editorial Casefile Redesign

## Non-Negotiable Reset

The existing dark aqua Workstation, grid-globe logo, screen proportion, right Context/Evidence Rail, and panel vocabulary are **rejected assets**. They are not a foundation to polish. The redesign must replace them with a visibly different operating environment while retaining the tested local-only contracts underneath.

> This is not a “new skin.” It is a new desktop composition, color grammar, type system, and program mark.

## Chosen Direction: Editorial Casefile

L EDITION will feel like a high-stakes digital casefile prepared for a permitted review: precise, warm, physical, and controlled. The memorable visual device is a broad document canvas with a **vermilion authorization edge**. Every important object is treated as a signed record rather than as a cyber metric or glowing status card.

| Decision | Rejected shell | Editorial Casefile replacement |
|---|---|---|
| Background | Cold near-black mineral field | Warm bone `#F5EFE3` with paper-white working surfaces. |
| Structural color | Teal/aqua | Ink blue `#14243B` with deep slate typography. |
| Primary permission signal | Aqua readiness | Vermilion `#D94D33`, used only for signed authority and decisive action. |
| Evidence signal | Pale electric blue in a dark rail | Cobalt `#2458D3`, used in local provenance and record links. |
| Exclusion signal | Clay accent in a dark panel | Burnt umber `#8F3D2E`, used as a fine line and label—not an alert card. |
| Status surfaces | Border-heavy dark panels | White or bone sheets, charcoal rules, and selective colored print marks. |
| Logo | Circular scope globe with `L` | Asymmetric dossier-fold silhouette with a cut-through `L` boundary. |
| Composition | Rails surrounding a dense center | Case Index → Dossier Canvas → bottom Context Ledger. |

## Identity: The Boundary Fold L

The new mark is an original vector symbol with no globe, ring, shield, hexagon, package, grid, or neon effect. It begins as a tilted rectangular dossier fold: a warm-white inside plane and ink-blue outer edge. A precise vermilion rule cuts through it, creating a tall, quiet `L` through negative space. A cobalt registration dot sits outside the fold as an evidence reference. The silhouette is deliberately **not circular**, so it cannot read as a reuse of the CyberBank family’s past globe experiments.

At 24px the mark reads as a compact folded `L`; at title scale it reads as a declared boundary and evidence bookmark. The outer perimeter is transparent. The vector will be evaluated in monochrome, on bone, on ink-blue, and at Windows icon scales before it touches the executable.

## Workstation Recomposition

The redesigned primary screen is a document control room, not a dashboard. It uses three active regions and a mechanical footer:

1. **Case Index** sits at left in a narrow white column. It contains the active local engagement, a linear sequence of `Brief`, `Boundary`, `Materials`, `Findings`, and `Delivery`, plus a compact source-of-truth status. It is no longer a decorative icon rail or a stack of cards.
2. **Dossier Canvas** is the dominant cream sheet. It is a continuous editorial work area with a colored edge, handwritten-style sectional numbers, strong labels, and disciplined form lines. The first view is titled `01 / Authorize the record`. Declared scope becomes a printed boundary list, not two dark boxes.
3. **Context Ledger** is a persistent lower workbench. It displays evidence provenance, latest finding, activity entries, and report readiness as a horizontal ledger. It replaces the old right-hand inspector and provides a stable place for details without compressing the primary form.

The top is a thin document header: boundary-fold mark, `CYBER BANK L EDITION`, engagement breadcrumb, a concise local-only statement, and a single decisive action. It contains no oversized product title, no glowing badge, and no generic cyber language.

## Typography and Spatial Rules

The product uses `Source Serif 4` only for numbered dossier headings and `IBM Plex Sans` for operational content. `IBM Plex Mono` remains for hashes, local paths, and audit IDs. Serif is used sparingly to create authority; it must never turn the UI into a themed template.

Spacing follows a paper-workflow rhythm: 6px for metadata, 12px field alignment, 20px section breathing room, 32px between workflow stages. Surfaces use hard 1px ink rules, not soft dark cards, glossy shadows, or rounded glass containers. Controls are rectangular with very slightly softened 3px corners. The primary vermilion action is flat and typographic; hover darkens it by one shade and keyboard focus uses an ink-blue double rule.

## Interaction and Safety Preservation

No control changes its safety meaning. The visible workflow still starts by collecting authorization reference and declared scope. Evidence is always explicitly selected locally and is never executed. Asset labels still reject URL/IP forms. Findings remain assessor-authored. Reports remain local JSON/Markdown snapshots. The redesign only changes comprehension and hierarchy; it does not introduce scanning, target input, remote data, credentials, payloads, cloud delivery, or command execution.

## Acceptance Criteria

The screenshot must make the previous UI unrecognizable while still communicating a professional local assessment record application. The viewer should immediately see a white/bone dossier canvas, vermilion authority rule, blue evidence register, non-circular `L` dossier-fold logo, top document header, left Case Index, and lower Context Ledger. There must be no teal, no dark card wall, no Globe-L, no former right-side rail, and no generic dashboard metrics.
